## 08 · Your first month

Theme: sand (light) + burnt orange · silent copy in `silent/`

You don't need a perfect plan. You need four weeks.

Nobody quits because the program was wrong. They quit because it was too much.

1. Three sessions a week — same days, in the calendar

3. Protein at every meal — a palm of it, don't count anything else yet
4. Walk the off days — twenty minutes, it's a habit not a workout
5. Weigh in once a week — same morning, same conditions

Do that for four weeks. Then we add.

## 10 · Progressive overload

Theme: clay + orange · silent copy in `silent/`

Same weight for six months = same body.

The gym doesn't change you. Beating last week does.

1. Add a rep — eight became nine, that session counted
2. Add a set — three to four, once the reps stop climbing
3. Add weight — smallest jump available, then rebuild the reps
4. Slow the way down — three seconds lowering is harder than more weight
5. Cut the rest — same work in less time is still more work

One of the five, every session. Write it down or you won't know.

## 11 · How it survives

Theme: night violet + orange · silent copy in `silent/`

Missing one session isn't the problem.

Missing the one after it is. That's where everyone loses a year.

1. Never miss twice — one is a bad week, two is a new habit
2. Ten minutes counts — turning up badly beats not turning up
3. Plan it on Sunday — decide once, so you're not deciding daily
4. Make it boring — the same few meals, the same few lifts
5. Judge the month — twelve sessions out of twelve is the only score

Motivation runs out. The plan doesn't.
